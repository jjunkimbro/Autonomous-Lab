# 집기 · 놓기 end-to-end 강화학습 설계 (v12)

2026-10-30. **사진은 이송 한 번에 딱 두 장**: 집기 전 1 장, 놓기 전 1 장. 준비 스캔 · 손 안 사진 · 놓은 뒤 사진은 없다.
두 경우 모두 이 사진 예산을 지킨다 (공정한 비교).

| | 1번: 비전만 (강화학습 0) | 2번: end-to-end 강화학습 |
|---|---|---|
| 집기 전 사진 1 장 | 표식 + 깊이로 장비 · 물체 자리를 잰다 (기하) | 정책 입력 |
| 놓기 전 사진 1 장 (물체를 쥔 채) | 표식 + 깊이로 장비 자리와 손 안 물체를 함께 잰다 | 정책 입력 |
| 집기 · 놓기 동작 | 잰 자리로 정해진 경로, 튜브는 곧게 내리기 | 정책이 손끝 속도 · 그리퍼를 직접 낸다 (잔차 아님) |
| 사진 사이 · 뒤 | 정해진 경로 | 정책이 손목 힘 · 로봇 상태로 이어서 판단 (영상은 그 한 장뿐) |
| 장비 사이 운반 | 경로 계획 (같음) | 경로 계획 (같음) |
| 끝났나 판단 | 손 폭 · 손목 힘 규칙 | 정책 출력 (끝 / 다시 / 사람) |

판정용 사진이 없으므로, 로봇의 "끝" 판단이 맞았는지는 시뮬레이터 정답과 맞대어 조용한 실패로 센다.

## 1. 한 이송의 흐름

```
[운반 끝: 출발 장비 앞]  사진 1 (집기 전, 정해진 촬영 자세)
   -> 집기 구간 (1번: 잰 자리로 경로 / 2번: 정책)          -> 빼냄
[운반: 경로 계획]
[도착 장비 앞]          사진 2 (놓기 전, 쥔 물체 + 받침이 함께 보이는 촬영 자세)
   -> 놓기 · 꽂기 구간 (1번: 잰 자리로 경로 + 곧게 / 2번: 정책) -> 놓음 -> 물러남
```

촬영 자세는 공칭 장비 기준 고정 (장비 앞 위, 받침 · 표식 · 손끝이 한 화면에 들어오게). 실제 장비는 ±5 mm · 높이 ±2 mm · ±2° + 하루 밀림만큼 다르다.

## 2. 2번 정책의 관측 · 행동

**학생 (실행 때) — 실물에서 얻는 것만**
- 그 구간의 사진 1 장 (RGB-D, 가까운 · 넓은 두 배율 96×96). 구간 내내 같은 사진을 본다 (다시 찍지 않는다).
- 사진을 찍은 뒤 손이 움직인 양 (로봇 관절에서 안다) — 사진 속 자리를 지금 손 기준으로 옮겨 쓰게.
- 손목 힘 · 돌림힘 최근 3 걸음, 그리퍼 폭, 손가락 닿음
- 목표: 물체 종류 · 스킬 · 장비 원핫 ("지정한 장소")

**선생 (학습 때만)**: 실제 장비 자세, 물체 자세, 접촉. 학생을 가르치는 데만 쓴다.

**행동 (20 Hz, -1 ~ 1)**: 공칭 장비 좌표계 손끝 속도 앞뒤 · 좌우 · 위 (최대 40 mm/s), yaw 속도 (J1 — J6 고정 그대로),
그리퍼 (닫기 / 벌리기), 끝내기 신호 (끝 / 사람 호출). 작업 상자 밖 (공칭 대비 ±25 mm · 위 +60 mm) 으로는 못 나간다.

## 3. 보상

원칙: 성공은 끝에서 크게, 중간 유도는 퍼텐셜 차이로만 (최적 정책을 바꾸지 않는다), 실물에서 못 하는 것은 비용,
**"끝" 이라고 말한 것이 틀리면 크게 벌한다** (사진 확인이 없으니 정책이 스스로 알아야 한다).

한 걸음

```
r = [γΦ(s') - Φ(s)]
  - 0.01                                  시간
  - 0.05 · max(0, F - 15 N) / 10 N        손목 힘
  - 0.2  · [로봇 몸 (손끝 제외) 이 장비에 닿음]
  - 0.005 · |a - a_prev|²
Φ = 2·k - 50·d[m] - 0.05·|yaw 오차[°]|     k = 단계 번호, d = 그 단계 목표점까지 거리 (정답)
```

| 스킬 | 단계 k |
|---|---|
| 판 집기 | 0 접근 → 1 쥠 → 2 받침 밖 3 cm |
| 판 놓기 | 0 접근 → 1 받침 면 → 2 손 벌림 → 3 물러남 |
| 튜브 집기 | 0 접근 → 1 쥠 → 2 벽 위 5 mm |
| 튜브 놓기 | 0 축 위 → 1 벽 아래 → 2 바닥 → 3 놓고 물러남 |

끝

| 끝남 | 보상 |
|---|---|
| "끝" + 실제 성공 | +10 (놓기는 + 2·(1 - 놓인 오차 / 허용)) |
| "끝" + 실제 실패 (조용한 실패) | -15 |
| "사람 호출" | -3 (성공했어야 할 걸 부르면 손해, 실패를 숨기는 것보다는 낫게) |
| 손목 힘 50 N 넘음 | -5, 그 자리에서 끝 |
| 떨어뜨림 / 공중에서 놓음 | -10 |
| 집기 전에 물체를 3 mm 넘게 밀어냄 | -5 |
| 시간 초과 (판 8 s · 튜브 10 s) | -2 |

**성공 정의 (시뮬레이터 정답, 두 경우 같음)**

| 스킬 | 성공 |
|---|---|
| 판 집기 | 두 손가락이 판에 닿음, 손 안 어긋남 ≤ 2 mm · 1°, 기울기 ≤ 1°, 받침에서 3 cm 빠짐 |
| 판 놓기 | 높이 오차 ≤ 0.5 mm, 기울기 ≤ 0.5°, 놓은 뒤 판이 0.5 mm 넘게 끌리지 않음, 손 3 cm 물러남 |
| 튜브 집기 | 쥠, 손 안 기울기 ≤ 3°, 쥔 높이 공칭 ±3 mm, 튜브 바닥이 벽 위 5 mm |
| 튜브 놓기 | 튜브 바닥이 자리 바닥 ±1 mm, 기울기 ≤ 2°, 손 벌리고 물러남 |

## 4. 학습 방법

1. **선생** PPO: 정답 상태만 본다. 스킬마다 모든 장비를 한 정책으로 (장비 원핫). CPU 24 환경 + A5000.
2. **학생**: 선생을 DAgger 로 따라 배운다. 입력은 사진 1 장 + 힘 + 상태 + 목표. CNN 은 A5000 에서 학습한다.
   사진이 한 장이라 실행 중 매 걸음 렌더링이 없다 (구간 시작 때 한 번) → 학습이 v9 학생보다 훨씬 싸다.
3. 학생이 선생보다 확실히 못하면 학생을 PPO 로 더 학습한다 (가치 함수만 정답 상태를 본다).

순서: 판 놓기 → 판 집기 → 튜브 놓기 → 튜브 집기.
